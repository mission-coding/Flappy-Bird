# Flappy Bird 🐦

A Flappy Bird-inspired arcade game built with Python and Pygame. Control the bird, fly through gaps between pipes, avoid collisions, and aim for a high score.

## ✨ Features

- Bird movement and flap mechanics
- Moving pipes and obstacle generation
- Collision detection
- Score tracking for passing pipes
- Welcome and game-over screens
- Bird animations and sound effects
- Restart functionality

## 🕹️ Controls

| Key | Action |
|---|---|
| Space | Flap / start the game |
| Up Arrow | Flap |
| Enter | Start or restart, depending on the screen |

## 🛠️ Technologies Used

- Python
- Pygame

## 🚀 How to Run

1. Install Python 3.
2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Run the game:

   ```bash
   python flappy.py
   ```

## 📁 Project Structure

- `flappy.py` — Main game file
- `gallery/sprites/` — Game sprites
- `gallery/audio/` — Sound effects and audio assets

Keep the asset folders in their original locations.
